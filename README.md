One line in which a robot vacuum explains why it missed a spot. The program writes the line to `entry.txt`.

## Entry

> I didn't miss that spot — my cliff sensor saw the rug fringe and filed it under 'certain death.'

## Why this angle

The field is flooded with union/picket-line jokes, adopted dust bunnies, and cats who outrank the vacuum. This line stays in the vacuum's own world instead: a cliff sensor — a real robot-vacuum feature — reads the rug fringe as a drop-off and deadpans the spot away as "certain death". It is the machine speaking in its own defensive voice, owning up to a failure by blaming its own hardware, and it needs no setup the reader has to supply.

## How to run

```sh
python3 main.py
```

This writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
